# Syndicate 🎭

Мультиагентная система для совместного выполнения задач. Синдицирует ответы от нескольких LLM через единый интерфейс, синтезируя итоговый результат с помощью мета-агента.

## Стек

- **Core**: Python 3.10+, LangGraph
- **UI**: Streamlit
- **Package Manager**: [UV](https://github.com/astral-sh/uv)

## Установка и запуск

Для управления зависимостями используется `uv`.

1. **Установка зависимостей:**

```bash
uv sync
```

2. **Настройка окружения:**

Скопируйте файл `.env.example` в `.env` и заполните необходимые значения:

```bash
cp .env.example .env
```

Конфигурация моделей задается через нумерованные переменные окружения:

- LLM_1_MODEL - имя модели
- LLM_1_URL - endpoint модели
- LLM_1_API_KEY - ключ доступа к API модели

> Количество агентов определяется автоматически по наличию переменных `LLM_N_....` Валидация осуществляется через Pydantic.

3. **Запуск приложения:**

```bash
uv run start
```

## Архитектура

Система работает в два этапа:

1. **Параллельная обработка:** Выбранные рабочие агенты (workers) одновременно анализируют запрос пользователя и генерируют свои варианты ответов.
2. **Синтез:** Мета-агент собирает все полученные ответы, анализирует их и формирует единый финальный результат, объединяя лучшие идеи и устраняя противоречия.
